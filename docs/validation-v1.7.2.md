# v1.7.2 全新镜像安装兼容验证

日期：2026-11-06。

现场新主控为 RK3588、Ubuntu 22.04.5、systemd 249、Linux 5.10.226。原镜像没有 UAV 业务服务；`systemctl list-unit-files 'uav-video*' --no-legend --no-pager` 在空匹配时返回 1、stdout/stderr 均空，旧安装器误当作检查失败。

现在只将该特定空结果视为没有旧服务，总线/权限错误、其他异常返回码及找到旧服务时仍拒绝安装。新增实际返回模式和失败场景测试。安装器完整回归 206 项通过。

全新 CIF 节点在第一次设置格式前返回 0×0 和空像素格式；现场节点经启动时协商可以正常输出 NV12 1280×720。预检现在只在这种明确空状态且驱动枚举支持 NV12 时允许后续协商，保留对错误查询、已选其他格式和不支持 NV12 的拒绝。

推流二进制、检测跟踪 worker、模型与 RK3576 云台程序均沿用 v1.7.1。其 RGA3/DMA32 实现、图像/旋转、十分钟并发和重启验证见 [v1.7.1 验证记录](validation-v1.7.1.md)。本版本不重新编译或改变算法。

新板按实际网卡名生成配置，默认 `gimbal`，三方案切换菜单仍完整安装。数据盘和日志由完整部署器处理；录像和点云采集按需启动。风扇及管理 Wi-Fi 地址的现场配置单独核对，不宣称通用安装器会操作未知型号的风扇控制器或改写 Wi-Fi。

现场安装与软重启验证：固定管理 IPv4 在重启后保持 manual；云台模式和三方案菜单恢复。下视 MIPI、D455i、云台可见光、云台红外及其四路低清，重启前后每路各连续解码 60 帧通过。风扇控制开机启用；`/var/log` 确认位于独立数据盘，轮转、自启和录像接口启用，未自动启动任何录像或点云采集。内核 taint 为 0，未发现 RGA 内存异常或 Oops。算法板/双网口模式仅验证菜单及网络计划，本次没有接入算法板做这两种模式的实际出图验收。
