- 发布归档：三套角色、算法运行库和电脑切换工具分别给出 SHA256；解包路径、常规文件类型、包内清单和嵌入算法归档校验；凭据与设备证书不进入公开包。

## 尚未解决、未代替的验收

算法板此前出现 `Bad rss-counter state`、页表/内核异常、RGA 提交失败，导致网络失联；本次打包时无人操作、持续供电又失联。归档已取得最新程序，但尚未确定内核异常触发原因，也没有修复厂家内核。此记录不能作为算法板持续运行稳定性通过的证明。

新设备需要匹配厂家完整镜像、原厂驱动与 IQ、可用数据盘，并在部署后逐路出图、重启、持续运行验收；新云台方向/速度/限位和重捕获转动须现场标定。文件系统测试、依赖预检和既有出图记录不等于新硬件整机验收。
